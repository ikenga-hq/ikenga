You can now make an outside link to a file from the app. When the server has file links turned on, a file's Share… menu (in Files and in the viewer) has a "Get a link" option: pick how long it lasts (1, 7 or 30 days, or never) and an optional passcode, and the link is shown once with a Copy button. It can't be shown again, so copy it then. Settings, People, Profile has a new Links panel listing the links you made, how often each was opened and downloaded, and a Revoke button. Admins also get an All links view to filter by account, revoke one link, or revoke all of an account's links. Nothing shows unless the server turned file links on.
