Outbox approvals now has its own icon in the left rail, right after Ngwa, with the pending-approvals count as a badge. It shows only while an approvals backend is active (and, inside a share, only for operators), and the Explorer Views row for it is gone. On desktop, every installed and enabled app pkg that contributes a view now gets a rail icon automatically (one per pkg, none if you already pinned it); disabling or uninstalling removes it. Right-click an app icon and choose "Hide from rail" to hide it; the pkg's row in Explorer Views has a "Show in rail" button to bring it back. The remote box has no pkg runtime, so it shows only Outbox approvals.
