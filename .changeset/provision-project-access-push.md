Server provisioner: three new optional profile keys for shared projects (a profile without them behaves exactly as before). `PROJECTS_ACCESS=("project=account [account...]")` restricts a project to exactly those accounts: its mirror is readable by them alone (read-only ACLs plus default ACLs, never world-readable even with `PROJECTS_READ=world`), a re-run revokes anyone no longer listed and closes a mirror that was world-readable, clones are created only for the listed accounts (an excluded account's existing clone is reported and never touched), and `refresh-projects` fast-forwards only the intersection with `PROJECTS_FASTFORWARD`; a restricted project's deploy token that is scoped to an outsider stops the run. `PROJECTS_PUSH_TOKEN_SECRETS=("project=SECRET")` lets accounts without a GitHub login push to the upstream: each clone gets a repo-local credential helper scoped to the upstream URL that reads the token from that variable in the session's environment at push time (the value is never written to a config, file or log), and the secret must reach every account of the project. `PROJECTS_SHARED_MAIN=(project)` makes a team repo's clones track `origin/<branch>` at the upstream (fetch and push) instead of `<account>/main`, and `refresh-projects` fast-forwards them from the upstream as the account.
