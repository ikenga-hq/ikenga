Outside file links now record who opened them. Each open or download of a link appears in the owner's audit list (once per visitor and hour, with the visitor's address and browser), the link's open and download counts and last-opened time update, and the owner gets a notification, and a push on an installed app, the first time anyone opens the file. Still off unless the server's file links setting is on.
